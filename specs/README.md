# Specs

Каталог markdown-планов для E2E-тестов: их пишет планировщик (Koda через
`playwright mcp`, либо человек) до генерации кода.

План описывает сценарий шагами и ожидаемыми результатами — этого достаточно,
чтобы по нему сгенерировать тест в `apps/web/e2e/`. Один план ≈ один тест.

Шаблоном служит план базовых операций TodoMVC из
[документации Playwright](https://playwright.dev/docs/test-agents).
